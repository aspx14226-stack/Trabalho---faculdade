# 🏋️ Academia Cabides — Calculadora de IMC

Projeto desenvolvido como atividade acadêmica com o objetivo de aplicar conceitos de desenvolvimento web na criação de uma página para uma academia, incluindo uma **calculadora de Índice de Massa Corporal (IMC)**.

## 📌 Sobre o projeto

O projeto consiste em uma página web voltada para uma academia fictícia chamada **Cabides**.

A página apresenta algumas informações e seções relacionadas à academia, além de uma calculadora de IMC, onde o usuário informa seu:

- ⚖️ Peso
- 📏 Altura

Após informar os dados, o sistema realiza o cálculo automaticamente e apresenta o resultado do IMC e sua respectiva classificação.

## 🧮 Fórmula do IMC

O cálculo é realizado utilizando a seguinte fórmula:

```text
IMC = Peso / (Altura × Altura)
```

### Exemplo

```text
Peso: 75 kg
Altura: 1,75 m

IMC = 75 / (1,75 × 1,75)
IMC = 24,49
```

## ⚙️ Funcionalidades

### Calculadora de IMC

O usuário informa seu peso e altura e, ao clicar no botão **"Calcular"**, o sistema:

1. Recebe o peso informado;
2. Recebe a altura informada;
3. Realiza o cálculo do IMC;
4. Exibe o valor calculado;
5. Apresenta a classificação correspondente.

Também existe a opção **"Limpar"**, que permite apagar os dados informados e realizar um novo cálculo.
